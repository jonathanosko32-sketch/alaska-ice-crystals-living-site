# Living World Rules

The Alaska Ice Crystals website is a living interactive property, not a normal template website.

- Visitors enter the property and move through it.
- Buildings, vehicles, Aurora, SKIE 27, animals and other approved pieces become interactive destinations.
- Motion can include camera travel, aurora, snow, smoke, fire, lights, wildlife movement and other approved effects.
- The world is built piece by piece from OSKO-created/approved assets.
- Never replace approved project pieces with generic internet assets.
- Never rebuild the whole world to make a local change.
- Change only the requested object or behavior whenever possible.
- Preserve approved checkpoints before major changes.
- Update BUILD_LOG.md, ASSET_MANIFEST.md and scene-map data as the world grows.
