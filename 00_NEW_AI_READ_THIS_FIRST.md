## Current phone delivery rule

OSKO is already installed on Osko's Android phone as an app/PWA with its own icon and startup experience. Phone development is delivered through the built-in TEST / KEEP / REJECT / ROLL BACK update workflow. Do not require a fresh installation for an ordinary OS update.

## Preservation rule

Always identify and protect the current working version before making a test version. Read the latest dated handoff note for the exact current checkpoint and backup. Never delete or overwrite the only working copy.
